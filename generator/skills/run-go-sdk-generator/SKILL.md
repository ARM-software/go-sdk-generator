# Skill: SDK Generator

## Quick use

Binary: `go-sdk-generator`

### Commands
- `generate`: Generate tool
- `schema`: Run `go-sdk-generator schema` to dump the embedded manifest schema as JSON for agents and other tooling
- `agent`: Run `go-sdk-generator agent --init` to initialise the repo skills under .agents/skills

---

## Configuration

Supported sources:
- CLI flags
- environment variables (prefix: `SDK_GENERATOR`)
- `.env`
- system keyring (when supported)

Use the `go-sdk-generator credentials` command to securely store secrets in the keyring when available.

OCI distribution is also available at `ghcr.io/arm-debug/go-sdk-generator`.
This is useful for CI, reproducible builds, and users who prefer not to install the tool locally.

GitHub documents container-registry authentication and package permissions at:
`https://docs.github.com/en/packages/working-with-a-github-packages-registry/working-with-the-container-registry`

On a local machine, if the package is not publicly accessible to the user's
account yet, log in to `ghcr.io` first. With the GitHub CLI installed and
already authenticated:

```bash
gh auth token | docker login ghcr.io -u "$(gh api user --jq .login)" --password-stdin
```

If `docker run` or `docker pull` fails with `403 Forbidden`, the GitHub
credentials usually do not have package-read access. The `read:packages`
permission is required, including in CI workflows that need to pull the OCI
image. For local-machine use with GitHub CLI credentials, refresh GitHub CLI
credentials, then log in to GHCR again:

```bash
docker logout ghcr.io
gh auth refresh --scopes read:packages
gh auth token | docker login ghcr.io -u "$(gh api user --jq .login)" --password-stdin
```


Linux packages installed via native package managers include the skills related to the tool under `/etc/go-sdk-generator/.agents/skills`.

## Commands

### `go-sdk-generator generate`

Generate tool

OCI usage:
```bash
docker run --rm ghcr.io/arm-debug/go-sdk-generator:v<version>-alpine generate
```

or:
```bash
docker run --rm ghcr.io/arm-debug/go-sdk-generator:v<version>-ubuntu generate
```


Required:
- `input`: path to tool definition file
- `output`: destination of the generated code

Optional:
- `overwrite`: regenerate all files
- `summary`: Write a human-readable summary to the selected destination. Allowed values: file, github, output.
- `summary_file`: Path to the summary file when summary is set to file
- `go_version`: targeted go version for the tool

Summary support:
- `summary=output` writes the human-readable summary to normal command output
- `summary=github` writes the summary to the GitHub Actions step summary when available
- `summary=file` requires `summary_file` and writes the summary to that path


Defaults:
- `overwrite` → false
- `output` → 
		func() string {
			pwd, _ := filesystem.CurrentDirectory()
			return pwd
		}()
