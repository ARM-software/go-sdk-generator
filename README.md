# go-sdk-generator

[![Go Badge](https://img.shields.io/badge/go-v1.24.4-blue)](https://golang.org/)

Generator for `go` SDKs and CLIs (for use by the online services team)

## Capabilities

### Formats

As well as `golang` built-in types, special types format are also supported by the genetator for ease of use:
- duration
- uuid
- json
- url
- version, semver
- port
- host
- email
