### Formats

As well as `golang` built-in types, special types format are also supported by the genetator for ease of use:

- duration
- uuid
- json
- url
- version, semver
- port
- host
- email


## Using this SDK

To include and use this SDK in your go project, add the following line to your `go.mod`:
```go
require (
    github.com/Arm-Debug/go-sdk-generator/generator   latest
    ...
)
```

run `go mod tidy`
