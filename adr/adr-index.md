# Architectural Decision Records

This page captures architecture and design decisions for `go-sdk-generator` and the rationale behind them.

## Key

- **ID**: Numeric ID for ADR.
- **Created**: Date at which the ADR was created.
- **Status**: One of:
  - ❓ Proposed
  - ✅ Accepted
  - 🚫 Rejected
  - 🗑 Deprecated or Superseded
- **Summary**: Title and/or a link to an ADR based on the [ADR Template](./ADR-TEMPLATE.md).
