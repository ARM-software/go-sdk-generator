# Architectural Decision Records

This page is to capture architecture and design decisions for the go sdk generator and the rationale behind them.

## Key

- **ID**: Numeric ID for ADR.
- **Created**: Date at which the ADR was created.
- **Status**: One of:
  - ❓ Proposed
  - ✅ Accepted
  - 🚫 Rejected
  - 🗑 Deprecated or Superseded
- **Summary**: Title and/or a link to a ADR based on the following [ADR Template](./ADR-TEMPLATE.md).
