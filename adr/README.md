# Architecture Decision Records

This folder gathers Architecture Decision Records (ADRs) for `go-sdk-generator`.

An ADR captures an important architectural decision, the context that led to it, the options that were considered, and the impact of the chosen approach.

Further reading:

- [Architectural decision on Wikipedia](https://en.wikipedia.org/wiki/Architectural_decision)
- [Further material and ecosystem around ADRs](https://adr.github.io/)

Use [ADR-TEMPLATE.md](./ADR-TEMPLATE.md) as the starting template when adding a new ADR.

Create ADRs for decisions that are fundamental to the generator architecture, or that need more rationale than can be captured in code, commit messages, or news files.
