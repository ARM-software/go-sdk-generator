# Security Policy

## Supported Versions

Security fixes are applied to the current development branch and to supported released versions at the maintainers' discretion.

If you are reporting a vulnerability, include the commit SHA, release tag, or package version you tested where possible.

## Reporting a Vulnerability

Do not report suspected vulnerabilities through public GitHub issues, pull requests, discussions, or other public channels.

Report security issues privately to `support@arm.com`.

Please include:

- a short description of the issue and the expected impact
- the affected version, tag, or commit SHA
- reproduction steps, proof of concept, or relevant logs where safe to share
- any known mitigations or configuration requirements

We will review the report, acknowledge receipt when practical, and work with the reporter on validation, remediation, and coordinated disclosure.
